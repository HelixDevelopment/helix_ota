TASK B — Benchmark regression baseline (CONTINUATION §5 item N)

Discovered existing benchmarks via grep -rl "func Benchmark": internal/api/bench_test.go, internal/store/bench_test.go. The token sign/verify crypto hot path (auth on every request) had NO isolated benchmark — existing api benchmarks measure it only bundled inside the full HTTP router path. FACT confirmed by the numbers: the reject path (472.7 ns) is ~3.6× cheaper than the accept path (1697 ns) because Verify fails at the constant-time HMAC compare before base64-decode + JSON-unmarshal — a forged-token flood cannot amplify the parse cost. This is the DoS-resistance property the fuzz target (A.3) asserts, now quantified.
